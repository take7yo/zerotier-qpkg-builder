# zerotier-qpkg-builder
# ZeroTier QPKG Builder for QNAP NAS  一个自动化的 ZeroTier One QPKG 构建工具，用于在 QNAP NAS 上创建 ZeroTier 虚拟网络客户端。  ## ✨ 特性  - 🔧 **一键构建**：自动化下载、编译、打包全过程 - 🐳 **Docker 容器化**：在隔离环境中构建，保证一致性 - 🎯 **参数化控制**：支持分步执行（下载、配置、构建） - 📦 **静态编译**：生成独立的可执行文件，无需外部依赖 - 🏷️ **版本可配置**：轻松修改 ZeroTier 版本 - 🖥️ **x86_64 架构**：支持主流 QNAP NAS 型号
